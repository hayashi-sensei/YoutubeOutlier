# Spec 016: Visual Generation Studio

## Goal

Generate YouTube thumbnails and LinkedIn visual assets.

## Scope

- Thumbnail concept generation
- Image prompt generation
- Provider selection
- Image generation
- Basic editable metadata
- Asset storage

## Asset Types

- YouTube thumbnail
- LinkedIn post image
- LinkedIn carousel cover
- Branded quote card
- Diagram/explainer image

## Requirements

- Generate visual strategy before image generation.
- Keep text overlays editable where possible.
- Support 16:9 thumbnails and LinkedIn-friendly ratios.
- Store prompts, provider, model, cost, and image URL.
- Use credit charging.

## Acceptance Criteria

- User can generate thumbnail concepts.
- User can generate at least one image asset.
- Image assets are saved and linked to content item.
