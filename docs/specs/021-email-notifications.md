# Spec 021: Email Notifications

## Goal

Send transactional and report emails.

## Scope

- Resend integration
- Daily report email
- Export ready email
- Billing-related emails where needed
- Email preference handling

## Requirements

- Respect report email preferences.
- Do not send daily reports unless enabled.
- Log email delivery status.

## Acceptance Criteria

- User can receive report email.
- Admin can see delivery status.
