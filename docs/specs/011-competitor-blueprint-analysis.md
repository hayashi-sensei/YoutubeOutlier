# Spec 011: Competitor Blueprint Analysis

## Goal

Extract repeatable content patterns from top-performing competitor videos.

## Scope

- Title pattern extraction
- Hook analysis
- Thumbnail pattern analysis
- Content pillar tagging
- Structure extraction
- CTA and angle analysis

## Requirements

- Analyze top outliers per channel.
- Store blueprint observations as structured records.
- Avoid direct copying language.
- Expose blueprint summaries in topic recommendations and content workspace.
- Expose each tracked channel's current blueprint on its competitor intelligence page.
- Allow regeneration of a channel-specific blueprint/report without losing the current inspectable result.

## Acceptance Criteria

- User can view competitor blueprint summary.
- User can view a blueprint for an individual tracked competitor channel.
- Blueprint data can influence generated outlines and scripts.
