# Spec 017: Repurposing Studio

## Goal

Repurpose YouTube content into LinkedIn and other written social formats.

## Scope

- LinkedIn post generation
- LinkedIn carousel outline
- X/Twitter thread draft
- Newsletter blurb optional
- Image concept for LinkedIn post

## Requirements

- Repurposing can start from topic, outline, script, or report.
- User selects format.
- Output uses user brand voice and CTA.
- Outputs are saved as content assets.

## Acceptance Criteria

- User can generate LinkedIn post from a YouTube outline.
- User can generate LinkedIn image concept.
- User can save repurposed content to calendar item.
