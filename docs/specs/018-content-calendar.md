# Spec 018: Content Calendar

## Goal

Provide a simple content calendar to move ideas from research to publishing.

## Scope

- Calendar item creation
- Status workflow
- Due dates
- Content asset linking
- Basic month/list views

## Statuses

- Idea
- Outline
- Script
- Thumbnail
- Scheduled
- Published
- Archived

## Acceptance Criteria

- User can save recommendation to calendar.
- User can update status and date.
- User can view calendar by month or list.
