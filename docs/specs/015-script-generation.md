# Spec 015: Script Generation

## Goal

Generate long-form YouTube scripts only when explicitly requested.

## Scope

- Full script generation
- Section-based script generation
- Regeneration
- Style settings integration
- Credit charging

## Requirements

- User clicks Generate Script.
- App shows credit cost before generation.
- Script uses user's writing style and brand settings.
- Script references selected outline and topic evidence.
- Generated scripts are versioned.

## Acceptance Criteria

- User can generate full script from an outline.
- Script is saved and can be edited.
- Credit ledger records the charge.
