# Spec 020: PDF DOCX Exports

## Goal

Allow users to export reports and content assets as branded PDF/DOCX files.

## Scope

- Export templates
- User branding
- PDF export
- DOCX export
- Storage and download links

## Requirements

- Exports include user/workspace branding.
- Export jobs run in background.
- Export failures are visible.
- Export file links expire or are access-controlled.

## Acceptance Criteria

- User can export a report as PDF.
- User can export a report as DOCX.
- Exports are associated with user and report.
