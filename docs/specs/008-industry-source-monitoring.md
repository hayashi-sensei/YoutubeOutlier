# Spec 008: Industry Source Monitoring

## Goal

Monitor user-provided industry websites and recommend content topics from new source items.

## Scope

- Source management
- RSS and page ingestion
- Source item dedupe
- AI source recommendation
- News-to-topic conversion

## Requirements

- User can add source URLs.
- App detects RSS when available.
- Store source items globally where possible.
- App recommends new sources based on niche.
- Latest source items feed topic recommendations.

## Acceptance Criteria

- User can add and archive sources.
- App fetches source items.
- Source items appear in reports and recommendations.
